# Milestone 7.1 — Chart of Accounts & Double-Entry Engine

Implemented:

- Hierarchical Chart of Accounts with system/control accounts
- Balanced journal posting engine
- Immutable posted journal entries and reversal journals
- General Ledger line generation
- Atomic account balance updates
- Idempotent source-based automatic posting foundation
- Default Pakistan-oriented COA seed
- Account/Journals/GL APIs, validation and permissions

Run: `npm run migrate:accounting` before using accounting endpoints.
