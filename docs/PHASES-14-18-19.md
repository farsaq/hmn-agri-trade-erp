# Phases 14, 18 and 19

## Phase 14 — Realtime Notifications

- Socket.IO authenticated user and role rooms
- Low stock, expiry, pending sale/supplier payment and overdue customer alerts
- New sale and purchase notifications
- Expense approval notifications
- Live notification bell, read/unread state and notification center
- Per-user in-app and email notification preferences

## Phase 18 — Audit Logs

- Create, update and delete audit records
- Before/after values and field-level changes where supported
- Login, failed login and logout events
- Generic mutation fallback logging for remaining API actions
- IP, user-agent/device, HTTP path, method and status code
- Date, user, action and entity filtering
- CSV export

## Phase 19 — Enterprise Roles and Permissions

- System roles: Admin, Manager, Accountant, Salesman, Warehouse, Operator and Viewer
- Custom role creation
- Per-module view/create/update/delete permissions
- Custom role assignment to users
- Backend permission enforcement
- Frontend sidebar permission filtering
- Role and permission changes recorded in audit logs
