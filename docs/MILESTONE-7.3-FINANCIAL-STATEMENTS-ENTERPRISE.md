# Milestone 7.3 — Financial Statements Enterprise

Version 4.7.3 adds General-Ledger-backed financial reporting:

- Trial Balance
- Profit & Loss
- Balance Sheet
- Direct-method Cash Flow foundation
- Financial ratios
- Comparative P&L periods
- Accounting dashboard KPIs
- PDF, Excel and CSV exports
- Frontend financial statements workspace

All figures are derived from posted General Ledger entries and active Chart of Accounts records. For production adoption, opening balances should be posted through balanced opening journals and organization-specific cash-flow source classifications should be reviewed.
