# Milestone 7.2 — General Ledger & Journals Enterprise

Version: 4.7.2

Implemented:

- Fiscal years and monthly accounting periods
- Period locking and posting validation
- Manual journal draft, edit, delete, submit, multi-level approve, reject, post and reverse workflow
- Maker-checker enforcement
- Manual/control-account posting restrictions
- Foreign/base currency and exchange-rate fields
- Cost center, department, project and branch dimensions
- Journal templates and recurring journal scheduler
- Journal attachments metadata
- Account statement with opening, running and closing balance
- GL source drill-down and reversal visibility
- PDF, Excel and CSV exports
- Balance reconciliation endpoint
- Accounting frontend page and navigation
- Enterprise permissions and migration script

Run:
`npm run migrate:accounting-enterprise`
