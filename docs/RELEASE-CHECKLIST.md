# Enterprise Release Checklist

- [ ] Tests, lint, coverage and frontend build passed
- [ ] No known critical/high dependency vulnerability accepted without sign-off
- [ ] Production secrets configured outside source control
- [ ] Database indexes and migrations verified
- [ ] Backup created and restore rehearsal passed
- [ ] Liveness, readiness, SLO status and metrics verified
- [ ] Logs include request IDs and redact sensitive data
- [ ] Rate limits, CORS, CSRF and security headers verified
- [ ] Monitoring alerts routed to responsible operators
- [ ] Deployment and rollback commands rehearsed
- [ ] Core sales, purchases, payments, inventory and accounting smoke tests passed
- [ ] Release owner and approval recorded
