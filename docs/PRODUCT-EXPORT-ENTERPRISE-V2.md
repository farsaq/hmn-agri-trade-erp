# Product Export Enterprise v2

Added formats: XLSX, CSV, PDF, JSON, XML, ZIP, barcode labels, QR labels.

Filters: category, brand, supplier, warehouse, active status, batch, lot, price range, stock value range, low/out of stock, expiry and date range.

Options: custom columns, saved browser template, PDF orientation, watermark, optional PDF password, product images, A4 label layouts, label sizing and print preview. XLSX includes frozen/filterable header, alternating rows and automatic widths.
